Manual de visualizaciones_ineCL

Versión 0.1.0. Paquetes R y Python para construir gráficos, mapas, tablas e indicadores estadísticos.
Autoría: Alejandro Henríquez Rodríguez. Titularidad: Instituto Nacional de Estadísticas de Chile (INE).
El código fuente es de uso interno por funcionarios del INE, conforme a la licencia incluida. Esta página es material público de consulta y no concede autorización para reutilizar los paquetes ni sus recursos de diseño. No se publican en CRAN ni PyPI.

El estilo procede del HTML entregado: Lato, azul #092C74, rojo #E31D1A, fondo blanco, bordes grises y separadores numericos chilenos: 1.234.567,89. La arquitectura editorial sigue el manual adjunto. Son herramientas tecnicas; no constituyen una aprobacion institucional del diseno o de una publicacion.

Instalacion rapida

Desde la carpeta descomprimida:

# Instala codigo local y los extras de mapas y exportacion.
python -m pip install "./python[mapas,exportacion]"

# Instala dependencias de CRAN y luego el paquete de esta carpeta.
install.packages(c("ggplot2", "plotly", "htmlwidgets", "htmltools",
                   "sf", "jsonlite", "rlang", "ragg", "svglite"))
install.packages("R/visualizacionesineCL", repos = NULL, type = "source")

Los requisitos de Lato, Chrome, Pandoc, Windows y Linux se explican en INSTALACION.

Primer grafico en Python

# Valores sin formatear; los separadores se aplican solo en la salida.
import pandas as pd
import visualizaciones_inecl as ine
datos = pd.DataFrame({"anio": [2024, 2025], "cantidad": [12500, 13400]})
meta = ine.Metadatos("Cantidad ficticia, segun anio", "Datos ficticios", ficticios=True)
v = ine.grafico_lineas(datos, "anio", "cantidad", meta)
v.guardar_html("salidas/lineas.html")
v.exportar("salidas/lineas.png")
v.guardar_csv("salidas/lineas.csv")

Tema TemaINE(...) y tema= tema_ine(fuente, tamano) para ggplot2

Python dimensiones en pixeles logicos; R en pulgadas. Las APIs son equivalentes en proposito y contratos, no intercambiables literalmente entre lenguajes. Tasas/porcentajes se entregan en unidades visibles, y los cortes del histograma incluyen el extremo superior del ultimo intervalo. Si se quieren intervalos exactamente iguales entre lenguajes, entregar el mismo vector de cortes.

La tabla equivalente de histogramas es de intervalos y frecuencias; la de mapas contiene la union territorial, incluyendo ausentes. Las tablas de apiladas porcentuales contienen los valores transformados a porcentaje, no las cantidades originales. Conservar el archivo de entrada para trazabilidad.

Instalacion y entorno

Python

Python 3.10 o superior. Se recomienda un entorno por proyecto; no sobrescribir el entorno utilizado por otras operaciones estadisticas.

# Windows: activar entorno y usar pip del mismo interprete.
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install ".\python[mapas,exportacion,desarrollo]"

# Linux/macOS: activar entorno e instalar desde la carpeta entregada.
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install "./python[mapas,exportacion,desarrollo]"

El nucleo usa pandas, numpy, Plotly y Matplotlib; mapas agrega GeoPandas y el extra exportacion agrega Kaleido para el motor Plotly opcional. El extra desarrollo instala herramientas de prueba, documentacion y empaquetado. Las dependencias transitivas se resuelven mediante pip. No se necesita cuenta de Plotly, servidor de mapas, token comercial ni conexion para usar las capas GeoJSON incluidas o los HTML autocontenidos.

PNG, SVG y PDF usan Matplotlib por defecto y no requieren navegador. Para exportar con el mismo motor interactivo, usar v.exportar(ruta, motor="plotly"); esa opcion usa Kaleido y necesita Chrome o Chromium. Si no esta instalado:

# Descargar Chrome solo si la politica del equipo lo permite.
import plotly.io as pio
pio.get_chrome()

Para un Chrome corporativo en ruta distinta, definir BROWSER_PATH antes de ejecutar Python. El HTML interactivo no necesita Kaleido ni Chrome instalado en el equipo que lo genera; si requiere un navegador para visualizarlo.

R

R 4.1 o superior. En Windows preferir paquetes binarios de CRAN, especialmente sf; compilar desde fuentes puede requerir Rtools. RStudio es opcional.

# Instala las dependencias y el paquete local; no descarga cartografia.
install.packages(c("ggplot2", "plotly", "htmlwidgets", "htmltools",
  "sf", "jsonlite", "rlang", "ragg", "svglite", "testthat", "roxygen2"))
install.packages("R/visualizacionesineCL", repos = NULL, type = "source")
library(visualizacionesineCL)
packageVersion("visualizacionesineCL")
help("grafico_lineas", package = "visualizacionesineCL")

R produce imagenes con ggplot2; no necesita Chrome. SVG usa svglite; PDF usa Cairo. HTML autocontenido con htmlwidgets requiere Pandoc: RStudio/Quarto suelen proveerlo, pero comprobar su instalacion. Si no esta disponible, usar exportar_html(v, ruta, autocontenido = FALSE) y distribuir tambien la carpeta de dependencias creada junto al HTML. No mover solamente el archivo HTML.

En Linux, sf desde fuente puede requerir GDAL, GEOS, PROJ y udunits2. Instalar las dependencias del sistema con los procedimientos del entorno institucional; el paquete no instala componentes del sistema automaticamente.

Tipografia

Instalar Lato en el sistema para que imagenes y navegador coincidan. Python resuelve Lato, Arial, sans-serif; R solicita Lato al dispositivo grafico. No se incrusta una fuente de Google Fonts por red: evita depender de internet. La carpeta recursos/fuentes/, si esta incluida, contiene archivos Lato y su licencia procedentes del paquete Ubuntu fonts-lato. Instalar los TTF y revisar su licencia antes de redistribuirlos de forma independiente.

Si Lato no esta disponible, Python usa alternativas; en R la sustitucion o el error dependen del dispositivo. Aplicar v$estatica + tema_ine(fuente = "Arial") permite exportar temporalmente con otra familia, declarando la desviacion.

Cartografia de Chile

Fuente adoptada

SUBDERE / IDE Chile, Division Politica Administrativa 2023, fecha de publicacion 29 de septiembre de 2023. Ficha oficial: https://geoportal.cl/geoportal/catalog/36391/Divisi%C3%B3n%20Pol%C3%ADtica%20Administrativa%202023

Descarga oficial: https://geoportal.cl/geoportal/catalog/download/912598ad-ac92-35f6-8045-098f214bd9c2

El conjunto se elaboro con participacion de SUBDERE, IGM, DIFROL e INE. Su ficha declara SIRGAS Chile, escala de referencia 1:50.000 y exclusion del Territorio Antartico Chileno. Estas propiedades corresponden al origen; las copias simplificadas de esta entrega no conservan precision a esa escala.

La revision de los archivos descargados encontro:

Capa Registros Campo de codigo Campo de nombre Region
REGIONES_v1.shp 16 CUT_REG REGION Derivada del codigo
PROVINCIAS_v1.shp 56 CUT_PROV PROVINCIA CUT_REG
COMUNAS_v1.shp 345 CUT_COM COMUNA CUT_REG

El CRS del archivo es EPSG:5360. La capa comunal no incluye la comuna Antartica. Una provincia llamada Antartica Chilena puede estar presente aunque no este el poligono de la comuna Antartica: no confundir nombre de unidad con cobertura de todo el territorio que pudiera asociarse a ese nombre.

No se afirma que DPA 2023 sea la version vigente mas reciente en 2026. Se identifico y descargo esta version oficial concreta para una entrega reproducible. Cada publicacion debe comprobar concordancia con los codigos, periodo estadistico y limites correspondientes a su operacion.

Capas incluidas

*_dpa2023_referencia.geojson preservan unidades y codigos del original, reproyectan a EPSG:4326 y simplifican geometria en EPSG:32719 con tolerancia maxima de 1.000 metros. El script reduce la tolerancia por unidad hasta que el cambio relativo de superficie proyectada queda bajo 0,5%. La tolerancia final por codigo se registra en el JSON. La simplificacion conserva la validez de cada poligono, pero no garantiza topologia compartida entre vecinos. Puede modificar superficies y bordes: no usar estas copias para medicion, interseccion analitica, areas ni asignacion de puntos a unidades territoriales.

Una simplificacion inicial uniforme de 1.000 metros produjo cruces tras reproyectar en dos geometrias y un cambio de superficie excesivo en comunas pequenas. Se reemplazo por la tolerancia adaptativa descrita arriba. Las capas finales no requirieron reparaciones y contienen cero geometrias invalidas. El script conserva una reparacion explicita como salvaguarda para otros datos y registra su uso; la funcion publica de carga rechaza invalidas sin repararlas.

procedencia.json registra checksum del ZIP original, checksums de las capas, conteos, errores maximos de superficie proyectada y CRS. Esos errores son una auditoria tecnica de la transformacion, no una garantia de precision geodesica. El ZIP original de aproximadamente 297 MiB no se incorpora al paquete para evitar una entrega innecesariamente grande. Se puede descargar y preparar:

# Tolerancia de referencia; usar --tolerancia 0 para geometria sin simplificar.
python scripts/preparar_cartografia.py /ruta/dpa2023.zip --tolerancia 1000

Las funciones tambien aceptan archivos originales SHP/GPKG/GDB/GeoJSON de otra version oficial mediante nombres de campos explicitos y CRS declarado. No estiman llaves a partir del nombre de un territorio.

Cobertura, calidad y procedencia en la publicacion

Incluir fuente de los indicadores y fuente/version de la cartografia. Una geometria real con un indicador ficticio no es una estadistica oficial. Mantener visible la cobertura declarada. Las vistas continentales necesitan nota del encuadre; los territorios fuera del encuadre no desaparecen de la tabla equivalente. Los mapas completos pueden verse estrechos por la forma de Chile y sus islas: se deja el ajuste de encuadre como decision editorial.

La ficha web consultada menciona una resolucion DIFROL N. 50 de 2019; el documento DESCRIPCION_DPA2023_v1.docx incluido en el ZIP menciona N. 87 de 2019. Se encontro esta discrepancia en las fuentes, por lo que no se inserta automaticamente una leyenda de autorizacion en mapas derivados. El documento y la ficha tambien senalan revision de productos derivados. Confirmar la leyenda y el procedimiento aplicable con el responsable cartografico antes de una circulacion institucional. Esta entrega tecnica no acredita esa validacion.

Otras fuentes oficiales verificadas

INE, Geodatos Abiertos: remite al catalogo Cartografia de Documentos y descargas, incluida la base APC 2023 de Censo 2024: https://www.ine.gob.cl/herramientas/portal-de-mapas/geodatos-abiertos

Manual del analista

Contrato de datos

Las funciones reciben pandas.DataFrame en Python y data.frame en R. Los argumentos de columnas son cadenas: "anio", "valor", "sexo". Los nombres pueden ser distintos en cada operacion; no se requiere renombrar a un esquema universal. No se ejecutan expresiones recibidas como nombres de columnas.

Los valores deben ser numericos sin formato: 1234.5, no "1.234,5". Fechas deben tener tipo fecha o una escala numerica ordenable; las etiquetas de meses en texto requieren una fecha subyacente o un factor ordenado. Una tasa 9,6% se entrega como 9.6, no 0.096, salvo conversion explicita anterior.

Lineas requieren una fila por periodo y serie. Barras requieren una fila por categoria y serie. Tortas requieren una fila por componente. Los diagramas de caja y dispersion reciben observaciones; histogramas reciben valores individuales. Una piramide demografica necesita ambos grupos en cada tramo. Paneles requieren una fila por periodo, panel y serie. Mapas requieren una fila por codigo territorial. Tablas muestran los registros recibidos.

Las funciones no calculan estimaciones de encuestas, ponderadores, tasas, intervalos de confianza, imputaciones ni reglas de secreto estadistico. Esas operaciones deben completarse y validarse antes de visualizar. Cuando haya estimaciones de encuestas, entregar los limites calculados con su diseno muestral y aclarar nivel de confianza en la nota.

Duplicados generan error; no se suman silenciosamente. Ausentes generan error por defecto en los graficos que exponen na; na="omitir" produce advertencia. No se imputa cero. Un mapa conserva en gris las unidades sin indicador y su tabla equivalente registra el ausente como Sin dato.

Metadatos y lectura accesible

titulo y fuente son obligatorios. Completar descripcion con el mensaje verificable, periodo, territorio, unidad, nota y actualizacion cuando corresponda. La libreria no inventa el hallazgo. ficticios=True en Python o ficticios=TRUE en R agrega una advertencia visible de demostracion.

El HTML coloca titulo y subtitulo fuera del lienzo, fuente y nota debajo, y una tabla equivalente accesible mediante Ver datos en tabla. La alternativa tabular complementa la descripcion. No se declara certificacion WCAG: los widgets y las interacciones requieren una evaluacion completa en el sitio anfitrion, incluyendo lector de pantalla y navegacion con teclado.

Uso de resultados

Python devuelve VisualizacionINE: figura, datos, metadatos, tema y decimales. R devuelve visualizacion_ine: estatica, interactiva, datos, metadatos y decimales. Es posible modificar la figura usando las APIs nativas, conservando metadatos y tabla. Si se cambia el dato representado, actualizar tambien la tabla equivalente; no basta con cambiar una etiqueta.

# Anotar una referencia; guardar mantiene el objeto y tabla original.
v.figura.add_hline(y=13000, line_color="#E31D1A", annotation_text="Referencia ficticia")
v.guardar_html("salidas/grafico.html")
v.exportar("salidas/grafico.svg")

# Modificar la version estatica e interactiva si ambas se van a publicar.
v$estatica <- v$estatica + ggplot2::geom_hline(yintercept = 13000, colour = "#E31D1A")
v$interactiva <- plotly::layout(v$interactiva, shapes = list(list(type = "line", xref = "paper", x0 = 0, x1 = 1, y0 = 13000, y1 = 13000)))
exportar_html(v, "salidas/grafico.html")

Integracion en HTML y Quarto

Python v.html(incluir_js=True) devuelve un fragmento con JS incrustado. Para varios graficos, incluirlo solo en el primero y usar False en los siguientes. Si el HTML ya carga Plotly, usar False en todos y verificar compatibilidad. El HTML de referencia carga Plotly 2.35.2; esta entrega genera figuras con una version mas reciente. Para reutilizar sus fragmentos, sustituir el script antiguo por el bundle probado con la entrega, o aislar el grafico con iframe. No cargar dos versiones en el mismo documento.

En ambos lenguajes se puede guardar el HTML y usar un iframe con titulo y altura adecuados. Ejemplo de marcado para el sitio anfitrion:

<!-- El archivo debe desplegarse junto al sitio; altura cubre grafico y tabla. -->
<iframe src="graficos/lineas.html" title="Cantidad segun anio"
        style="width:100%;height:720px;border:0" loading="lazy"></iframe>

El iframe no ajusta automaticamente su altura a una tabla expandida; permitir su desplazamiento o implementar comunicacion entre documentos si se necesita altura dinamica. La integracion nativa en Quarto evita ese problema: ejemplo ejemplos/integracion_quarto.qmd. En R, imprimir v$interactiva y agregar titulo, fuente y tabla_html(v$datos) como en el ejemplo.

Las tablas de esta version son consultables mediante desplazamiento y HTML semantico; no implementan filtros, paginacion ni ordenamiento interactivo. CSV permite explorar los datos en otro programa. Una tabla grande debe publicarse como descarga y una seleccion editorial en la pagina.

Mapas

Se incluyen capas oficiales transformadas y simplificadas para referencia visual. Ver CARTOGRAFIA.md antes de cambiar cobertura o version. region="13" selecciona la Region Metropolitana en mapas provinciales y comunales; omitirlo representa el pais. vista="completa" conserva el encuadre de todas las islas presentes; vista="continental" cambia el encuadre y requiere declarar que no se ven todos los territorios. Los registros siguen en la tabla.

limites=(5,35) en Python y limites=c(5,35) en R fijan una escala comun a varios mapas. Valores fuera de limites generan error. No hay clasificacion Jenks, cuantiles ni inset automatico para islas en esta version. Para tasas con precision insuficiente o supresion, no sustituir el valor por cero: construir una capa editorial con el tratamiento de calidad correspondiente.

Los mapas interactivos usan un plano de longitud/latitud con proporcion fija de visualizacion; son mapas tematicos de referencia, sin escala cartografica, sin herramienta de medicion ni teselas. Los mapas estaticos R usan coord_sf. Las escalas cromaticas y unidades coinciden; no se promete identidad pixel a pixel entre los motores de R y Python.

Revision antes de publicar

Decisiones y limites

Se ofrecen tortas y donas porque el encargo las solicita; el manual aconseja evitarlas salvo composiciones muy simples. No se fuerzan como salida por defecto. La piramide de composicion usa barras centradas de alto constante; no un embudo con areas ambiguas. La piramide demografica compara dos grupos.

No se ofrecen ejes Y dobles como patron generico. Para medidas de distinta unidad deben construirse dos figuras o paneles separados con sus metadatos. Los paneles incluidos estan disenados para una misma medida y escala.

No se calculan intervalos a partir de datos crudos. No se garantiza que los colores funcionen solos en blanco y negro o ante todas las deficiencias de vision. La tabla equivalente y las etiquetas son parte de la alternativa. No se agregan estimaciones nacionales por suma de tasas regionales.
